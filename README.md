# ALX Backend

Backend development exercises completed as part of the ALX curriculum. The projects cover common techniques for building responsive and reliable backend services.

## Topics

- Pagination
- Caching strategies
- Internationalization (i18n)
- Queuing systems with JavaScript

## Repository structure

| Directory | Topic |
| --- | --- |
| `0x00-pagination` | Pagination |
| `0x01-caching` | Caching |
| `0x02-i18n` | Internationalization |
| `0x03-queuing_system_in_js` | Queuing systems |

Each project directory contains its own exercises and supporting files.

## Requirements

Requirements differ by project. Check each directory for its language version, dependencies, and setup instructions. JavaScript projects may include a `package.json` with the required scripts and packages.

## Running a project

Follow the instructions in the project directory. For a JavaScript project with a `package.json`, install its dependencies before using the scripts defined there.

## Note

This repository contains learning projects. Their implementations are intended for coursework and may need further work before production use.
